# Overview

This project was created as a way for me to learn the framework of games and the basics of pygames.

The game is Othello and requires two players. If you are unfamiliar with the rules of Othello, heres a link to the official rules. [Othello Rules](https://www.worldothello.org/about/about-othello/othello-rules/official-rules/english)

This project uses mouse inputs, the spacebar, and the "r" key.
* Mouse inputs: Clicking on a square will place a piece if it is a valid move.
* Spacebar: Pressing the spacebar passes the current player's turn. This should be used if the current player has no valid moves.
* "r" Key: Pressing this key will reset the game back to the start.

When every square is filled, the loser's pieces turn gray. If there is a tie, all pieces turn gray.
